# 业务目标

为 InforCenter 9.6 的 **BOM 管理**增加“转量产”入口：从当前打开的工艺 BOM 视图中识别符合规则的试制物料，先由用户核对待转码清单，再触发量产物料创建、BOM 替换、颜色表同步与 SAP 接口同步。

## 参考模块 / 菜单 / 页面

- **模块**：BOM 管理
- **菜单**：产品数据管理 → BOM管理 → 加载根节点（已运行时验证）；扩展入口：菜单栏“其他操作 → 试制转量产”（已按用户指定的目标位置更新原型，原厂挂载实现待确认）。
- **页面**：结构管理器：气缸体总成/12100-2CB -A401/A.001(Design)(最新版本)（已运行时验证）。
- **需求来源**：`【新大洲本田摩托（苏州）有限公司ECM PlatForm项目】二次开发需求规格说明书_V0.12.docx`，4.3「BOM管理」/ `UC_FD_01_04`，文件 SHA-256：`bd2bfd0611e6f232030cdde1e97d014411243c927f235ba796bf4296cf4387a0`，读取时间：2026-09-15。

## 已提取需求证据

1. 在 BOM 管理页面新增“转量产”功能按钮，仅支持车型级物料调用。
2. 选中部品番号须匹配 `^\w*-(?:1|2)-\w*$`；不匹配提示：`仅可对车型进行转量产！！`。
3. 从车型物料番号提取前三位；以示例 `2CD` 组织匹配表达式 `\w*-2CD[A-Z]-\w*` 遍历 BOM；将匹配物料列为待转码清单并弹窗展示。
4. 待转码清单可导出，且只导出两列数据；原文未说明列名。
5. 用户确认后：保存当前打开视图的原 BOM 结构为试制状态基线；原物料另存为新量产物料；属性不变，仅编码转换；在当前视图以替换方式替换原物料，保留子件、层级、数量。
6. **用户确认的演示映射**：`8125A-2CDB-A505 → 8125A-2CD -A500`、`81300-2CDB-A600 → 81300-2CD -A600`、`82100-2CDB-A617-M1_TYPE1 → 82100-2CD -A610-M1_TYPE1`。据此演示末段保留前 3 位并将第 4 位重置为 `0`；`2CDB` 演示为 `2CD `（末尾空格）。完整编号适用范围仍仅以这 3 个已确认示例为证据。
7. 查询颜色表的颜色部品编码列，以新量产编码插入对应记录；其他列不变；调用颜色接口同步 SAP。**用户确认：本次演示忽略颜色表与颜色接口。**
8. 约束：父件及其下级子件均符合条件、但中间层级物料不符合条件时，下级子件不执行转码。**用户确认：排除该中间层级以下整个分支。**

## 原型范围与验收标准

### 范围

- 以独立 HTML 展示的**需求原型**，不改动 InforCenter 原厂文件，也不调用数据库或 SAP。
- 展示 BOM 浏览上下文、车型节点选择、转量产入口、两步核对弹窗、待转码表格、规则说明、仅两列导出模拟、执行结果与可访问的错误提示。
- 样例数据只用于演示交互；不是生产数据、真实 BOM 或接口结果。

### 原型验收

- 当未选中节点或选中非车型级编码时，阻断操作并展示原文规定提示。
- 当选中符合条件的车型节点时，展示全量待转码清单、已确认的编码映射和层级约束说明；不提供逐项取消；导出仅含“原物料编码、原物料名称”两列。
- 二次确认仅提示本次的编码规则演示边界；确认后显示演示结果。基线、物料另存/替换、颜色表同步及 SAP 同步不在本次原型范围。
- 页面在桌面与窄屏下均可操作；所有操作控件可用键盘访问，焦点可见；不以颜色作为唯一状态表达。
